# Landlord 术语表

斗地主子项目里使用的领域用语。代码标识符用括号里的英文。

| 术语 | 含义 | 不要说成 |
| --- | --- | --- |
| 牌（card） | 一张牌，一个字节：高半是花色，低半是点数 | |
| 点数（rank） | 3 最小，然后 4 … K、A、2、小王、大王。2 和王不能进顺子 | 牌面、数值 |
| 手牌（cards / card array） | 一家手里的一组牌 | 牌堆 |
| 牌型（hand） | 一手合法的出牌，由主体、带牌、是否成链三部分确定 | 一手、组合 |
| 主体（primal） | 决定牌型大小的部分：单张、对子、三张、四张、炸弹、王炸 | 主牌 |
| 带牌（kicker） | 主体带上的牌：三带一的那一张、三带二的那一对、四带二的两张或两对 | 副牌、踢脚 |
| 链（chain） | 主体跨连续的点数：顺子、连对、飞机 | 顺 |
| 炸弹（bomb） | 四张同点数，不带牌；压一切非炸弹和更小的炸弹 | |
| 王炸（nuke） | 大小王一起；最大 | 火箭 |
| 规则 module | 判定一组牌是不是牌型（`hand_parse`）、两手牌谁大（`hand_compare`） | |
| 拆牌（analysis） | 把手牌分解成若干牌型，覆盖全部手牌且互不重叠 | 分析、理牌 |
| 手数 | 几手能出完，越少越好。`standard` 与 `advanced` 数的是拆牌结果里牌型的个数，`counted` 把带牌并进三张那一手 | 评估值、权重 |
| 领出（lead） | 轮到自己且没有要压的牌时出牌 | 自由出牌 |
| 压牌（beat） | 出一手比上一手大的同类牌型，或炸弹、王炸 | 管、跟 |
| 压牌搜索（beat search） | 在手牌里找出所有压得过给定牌型的牌型 | |
| 不出（pass） | 轮到自己但选择不压 | 过 |
| 叫分（bid） | 开局各家出价 1–3 争当地主，出价最高者当 | 抢地主 |
| 底牌（kitty） | 叫分后归地主的三张牌 | |
| 地主 / 农民（landlord / peasant） | 一局里的两方：地主一家对农民两家 | |
| 座位（seat） | 牌桌上的位置 0、1、2 | 玩家编号 |
| 局面（view） | 一个座位在某一时刻可以知道的全部：自己的手牌与拆牌、上一手及出牌者、各家剩余张数、已出的牌、叫分、地主是谁 | 状态、上下文 |
| 种子（seed） | 决定一局牌的那个数；同种子同局 | |
| 基线（baseline） | 固定种子范围内每一局的结果摘要，用来确认改动没有改变对局 | 快照 |
