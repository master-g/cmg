# 13: const、枚举与结构化牌型

**What to build:** 从声明就能看出函数会不会修改数据：只读的指针参数都标注 `const`。点数、花色、牌型的主体与带牌方式、对局阶段与状态、玩家身份都是枚举，对应字段使用枚举类型。牌型不再靠位运算宏拼装和拆解，而是结构化表示。牌型规格表是带字段名的结构体数组，不再用魔法下标。
