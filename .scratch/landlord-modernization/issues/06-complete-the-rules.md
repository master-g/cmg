# 06: 规则 module 补齐

**What to build:** 规则 module 与斗地主的实际规则一致：以 A 结尾的顺子、连对、飞机被识别为合法牌型；任意组数的飞机带单张、带对子被识别（包括 15 张的三组带三对、20 张的四组带四对）；含重复牌的输入被判为非法；识别牌型不再修改调用方传入的牌。规则 module 目前不在出牌路径上，本工单不影响任何对局。

**Blocked by:** 01（landlord 自检接入 make test）

**Status:** ready-for-agent

- [ ] 用例表新增并通过：`TJQKA`、`QQKKAA`、`KKKAAA` 合法
- [ ] 用例表新增并通过：三组飞机带三对、四组飞机带四对合法
- [ ] 用例表新增并通过：含同一张牌两次的输入非法
- [ ] 用例表含反例：含 2 或王的链非法、长度不足的链非法
- [ ] 大小比较有用例：同牌型比点数、炸弹压非炸弹、王炸最大、牌型或长度不同不可比
- [ ] 识别牌型后调用方的牌保持原样
- [ ] 基准程序的胜负数不变
- [ ] `make fmt` 后工作区无改动，`make test` 通过
