# 12: 牌型列表改值类型，删除容器与内存追踪

**What to build:** 牌型列表是容量有上限的值类型（一家最多 20 张牌，拆牌手数有界），不需要堆分配，也就没有谁来释放的问题。搜索树成为拆牌 module 的内部细节。通用链表与树 module 删除，自写的内存追踪删除，内存检查交给 sanitizer。两份洗牌实现合并为一份，没有调用方的随机数数组播种删除。
