# 09: AI 只做决定

**What to build:** AI 的 interface 收窄为：拿到一份只读的局面，返回一个决定——叫几分，或者出哪手牌、不出。AI 只能看到自己的手牌和公开信息（各家剩余张数、已出的牌、身份、上一手及出牌者）。扣牌、更新上一手、记录出牌、重算拆牌都由 Game 完成。两个 AI 共用同一份压牌决策，差异只是注入的拆牌与评估方式。玩家与 Game 的互相依赖用前向声明解开，interface 带真实类型。

**Blocked by:** 08（「谁压得过谁」只留一份）

**Status:** ready-for-agent

- [ ] AI 的 interface 中没有 `void *`，参数是只读的
- [ ] AI 的代码不再修改任何局面状态，包括自己的手牌
- [ ] AI 无法通过 interface 读到其他玩家的手牌内容
- [ ] 压牌决策只有一份实现，两个 AI 通过注入的拆牌与评估方式区分
- [ ] 可以在不创建 Game 的情况下给 AI 一个构造的局面并断言它的决定（自检至少一例）
- [ ] 基线与改动前完全一致
