# 07: 每一手出牌都经规则校验

**What to build:** Game 有一个出牌入口：收到一手牌后由规则 module 判定牌型，以及在需要压牌时是否确实大于上一手；不合法的出牌不会进入牌局。牌型以规则 module 的判定为准，不采信 AI 的标注。因此暴露的 AI 缺陷一并修掉：出牌里同一张牌出现两次、三带一被标成三张、统计可带的单张与对子时漏掉最后一手。整局不变量进入自检。本工单允许改变对局结果，基线随之更新。
